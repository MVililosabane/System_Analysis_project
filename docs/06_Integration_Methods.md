# 6. Интеграционные методы

В этом разделе представлено описание методов микросервиса «Клиент», разработанных в рамках проекта.

---

## 6.1 МС Клиент Метод 1 — Создание клиента

Метод принимает данные клиента, сохраняет их в базу данных и возвращает уникальный идентификатор клиента.

### Входящее сообщение

| Описание | Атрибут | Тип данных | Обязательность | Возможные значения |
|----------|---------|------------|----------------|-------------------|
| Фамилия | lastName | string(30) | Да | от 2 до 30 букв (кириллица) |
| Имя | firstName | string(30) | Да | от 2 до 30 букв (кириллица) |
| Отчество | middleName | string(30) | Нет | от 2 до 30 букв (кириллица) |
| Пол | gender | string | Да | Мужской, Женский |
| Дата рождения | birthDate | date | Да | гггг-мм-дд |
| Серия паспорта | passportSeries | string(4) | Да | 4 цифры |
| Номер паспорта | passportNumber | string(6) | Да | 6 цифр |
| Email | email | string(50) | Да | паттерн email, уникальный |
| Телефон | phone | string(20) | Да | номер телефона, уникальный |
| Семейное положение | maritalStatus | string | Да | В браке, Холост |
| Количество детей | childrenCount | int | Да | целое число ≥ 0 |
| Зарплатный клиент | isSalaryClient | boolean | Да | true, false |
| Рабочий статус | employmentStatus | string | Да | Безработный, Самозанятый, Владелец бизнеса, Наемный работник |
| Дата начала работы на первом месте | firstEmploymentStartDate | date | Нет | гггг-мм-дд |
| Дата начала работы на текущем месте | currentEmploymentStartDate | date | Нет | гггг-мм-дд |
| Наименование работодателя | employerName | string(100) | Нет | |
| Руководитель | isManager | boolean | Да | true, false |
| Ежемесячный доход | monthlyIncome | decimal(15,2) | Да | > 0 |

### Исходящее сообщение

| Описание | Атрибут | Тип данных | Обязательность |
|----------|---------|------------|----------------|
| Идентификатор клиента | clientId | string | Да |

### Обработка ошибок

| HTTP-код | Название ошибки | Описание |
|----------|-----------------|----------|
| 400 Bad Request | Ошибка валидации | Не заполнены обязательные поля |
| 409 Conflict | Конфликт данных (дубликат) | Клиент с таким email/телефоном/паспортом уже существует |
| 500 Internal Server Error | Внутренняя ошибка сервера | Проблема с БД, генерацией Id и т.д. |

---

## 6.2 МС Клиент Метод 2 — Начитывание клиента

Метод принимает идентификатор клиента и возвращает его полные данные из базы данных.

### Входящее сообщение

| Описание | Атрибут | Тип данных | Обязательность |
|----------|---------|------------|----------------|
| Идентификатор клиента | clientId | string | Да |

### Исходящее сообщение

| Описание | Атрибут | Тип данных | Обязательность |
|----------|---------|------------|----------------|
| Идентификатор клиента | clientId | string | Да |
| Фамилия | lastName | string | Да |
| Имя | firstName | string | Да |
| Отчество | middleName | string | Нет |
| Пол | gender | string | Да |
| Дата рождения | birthDate | date | Да |
| Серия паспорта | passportSeries | string | Да |
| Номер паспорта | passportNumber | string | Да |
| Email | email | string | Да |
| Телефон | phone | string | Да |
| Семейное положение | maritalStatus | string | Да |
| Количество детей | childrenCount | int | Да |
| Зарплатный клиент | isSalaryClient | boolean | Да |
| Рабочий статус | employmentStatus | string | Да |
| Дата начала работы на первом месте | firstEmploymentStartDate | date | Нет |
| Дата начала работы на текущем месте | currentEmploymentStartDate | date | Нет |
| Наименование работодателя | employerName | string | Нет |
| Руководитель | isManager | boolean | Да |
| Ежемесячный доход | monthlyIncome | decimal(15,2) | Да |

### Обработка ошибок

| HTTP-код | Название ошибки | Описание |
|----------|-----------------|----------|
| 400 Bad Request | Ошибка валидации | Неверный формат clientId (не соответствует UUID) |
| 404 Not Found | Клиент не найден | Клиент с указанным Id не существует |
| 500 Internal Server Error | Внутренняя ошибка сервера | Проблема с БД, ошибка чтения данных |
